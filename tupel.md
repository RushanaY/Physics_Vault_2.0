in [[Set]]s elements can be in any order, where as in a **tupel** the elements are **orderd** 

# definition
$$x : = (x_1, x_2, ..., x_n)$$
if we want the i-th component, we call it $x = (x_i)_{i \in \{1,2,...,n\}}$ 

In order to define a tupel through a set: $$(x_1, x_2) : = \{x_1, \{x_1, x_2 \}\}$$ 


This allows to define the  [[Carteisan product]] $$ M \times N : = \{ z| \exists x \in M, y \in N: z = (x,y)\}$$
